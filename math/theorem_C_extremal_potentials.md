# Theorem C — extremal potentials (T0-06..T0-08)

Statements: `U_b`/`V_b` Bellman inequalities with empty continuation for `V`;
sandwich `V ≤ H ≤ U` for every feasible `H` (path telescoping both sides);
at valid `b`, `U_b, V_b ∈ F_{n,b}` (diagonal value `V_b(d) = 0` because
validity forces all continuation regrets `≤ 0` while stopping gives `0`).
