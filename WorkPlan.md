## 1. The chain this plan implements (frozen, do not reorder)

```text
exact finite paired game → exact b_n* → (U,V,G) → critical paths/cycles
→ forced ΔH → structural law H → universal Pair Access Lemma
→ approximate monotonicity → dynamic optimality
   (or, on the negative branch: explicit infinite unbounded witness family)
```

Positive endpoint: universal constant `b` + structural `H(A,B) ≥ 0`, `H(T,T)=0`, with KEEP `c(B,x)+H(S_xA,S_xB)−H(A,B) ≤ b·c(A,x)` and DELETE `H(S_xA,B)−H(A,B) ≤ b·c(A,x)`, telescoping to `Splay(Y,T) ≤ b·Splay(X,T)` for all `Y ⪯ X`, then Levy–Tarjan → dynamic optimality.
Negative endpoint: explicit infinite family `(T_n,X_n,Y_n)`, `Y_n ⪯ X_n`, with ratio → ∞ (disproves approximate monotonicity, hence — via Levy–Tarjan — dynamic optimality for Splay).
Finite computation is discovery + falsification only; never a substitute for the universal argument (§§25–26 claim levels enforced in WP-6).

Frozen contract essentials (used by every WP phase): keys `[n]={1..n}`; BST universe `T_n` (Catalan `C_n`); root depth `0`; cost `c(T,x)=d_T(x)+1 ∈ [1,n]`; bottom-up Splay with the 5 fixed cases (ZIG, LL, RR, LR, RL) + post-rotation/BST/root assertions; pair state `(A,B)`; diagonal `Δ_n`; KEEP `K_x(A,B)=(S_xA,S_xB)` with `a=c(A,x),y=c(B,x)`; DELETE `D_x(A,B)=(S_xA,B)` with `a=c(A,x),y=0`; edge identity `(source_state_id,mode,key)`, `mode 0=KEEP,1=DELETE`; deterministic edge order `K(1..n),D(1..n)`; authoritative domain `R_n` = diagonal-reachable pairs only (forward-closed; unreachable states never enter solver/mining inputs — threat T1); regret `w_b(e)=y−b·a`, slack `ℓ_b(e)=b·a−y=−w_b(e)`, integer-scaled `L_{p,q}(e)=p·a−q·y` at `b=p/q` reduced; `b_n* = sup path Σy/Σa = inf{b : all diagonal-rooted L_b(P)≥0}`, sanity `1 ≤ b_n* ≤ n` (`BN_SANITY_FAIL` otherwise); no finite-attainment assumption (TRANSIENT / CYCLIC / MIXED); canonical `U_b(s)=inf_{Δ⇝s}L_b`, `V_b(s)=sup_{s⇝*}W_b` (empty continuation allowed, so `V≥0`), feasible set `F_{n,b}` (`H≥0`, `H=0` on diagonal, `H(s′)−H(s) ≤ ℓ_b(e)`), extremal theorem target `V ≤ H ≤ U` with `V,U ∈ F`, gap `G=U−V`, FORCED ⟺ `G=0` by exact integer equality; rationality + denominator bound `q ≤ n·R_n` (usable only after theorem T0-13 PROVED); two-sided certificate (upper feasible integer potential + transient and/or cyclic zero-slack lower witness) as the sole seal condition; - *Derivative datasets:* for each `FORCED_DELTA` edge `s→s′` compute `ΔF_j=F_j(s′)−F_j(s)`; exact target `ΔH(e)=ℓ_b(e)`, scaled `q·ΔH=L_{p,q}(e)`; denominators cleared for integral system.
- *How the "models" are trained (exact, not statistical):* search sparse `H=Σα_jF_j` with `Σα_jΔF_j(e)=ℓ_b(e)` on discovery forced edges; versioned coefficient domains searched in declared order (integers `[−M,M]` → rationals with denominator ≤D → nonnegative-only → signed) — each domain expansion is a new hypothesis-search version, never silent. Rank primarily by (1) exact satisfaction count, (2) exact max derivative residual, (3) expression complexity, (4) cross-`n` stability — float `R²`/correlation/MI are secondary exploration only. - *Kernels:* candidate `K_j:R_n→K_j` from declared primitive coordinates only (never `U/V/G/H/criticality/state-ID/full-pair-hash` unless designated `FULL_STATE` baseline → static audit); value-separation test (same `K`, different `V/U/G` → `KERNEL_VALUE_INSUFFICIENT` + lexicographically smallest separating pair); primitive transition-preservation test per key/mode (`c_A`, KEEP-observable `c_B`, successor-kernel equality under identity key correspondence; DELETE `y=0` but `c_B(x)` retained as observable; relabeling variants only with explicit key bijection, never unlabeled isomorphism); ablation from overcomplete kernel (ancestor+parent+interval+subtree/access-path/crossing/heavy) removing one family at a time → sharpness table (coordinate, smallest failing `n`, witness pair, value/successor mismatch, type); full-state control must pass or pipeline is broken.

**Model specifics & resultant benchmarks (required by task):**

- *Also:* static audits (F01 no-U/V/G-read; K-no-answer-smuggling; H-state-only), mutation controls (WP-5), minimal-inconsistent-subsystem preservation — all logged.

## 9. Global charter: models, benchmarks & brutal anti-overfitting (binds WP-4/5; audited in WP-6)

1. **What "models" means here:** there are no neural nets, no stochastic fits, no black boxes (forbidden as theorem statements). Trainable objects are: (a) sparse exact linear combinations over versioned state-only features; (b) structured nonlinear atoms; (c) kernel coordinate subsets; (d) versioned `H` formulas. "Training" = exact equation solving / combinatorial search over discovery forced-derivative equations — never gradient descent on a loss, never `R²` selection.
2. **Training specifics (frozen before seeing holdout):** discovery equations from `n=2..5` forced edges; coefficient domains versioned (`ℤ[−M,M]` → `ℚ_{den≤D}` → nonnegative → signed); feature schema `F-v0.1` immutable during a search version; ranking `(exact-count, max-residual, complexity, cross-n)`; basis + minimal-inconsistent-subsystem analysis per matrix.
3. **Resultant benchmarks (discovery):** exact satisfaction counts, exact max residuals, complexity, rank/nullity, kernel value/transition verdicts, stratified tables.
4. **Brutal validation on ENTIRELY different benchmarks (no overfitting):** (i) different sizes (`n=6` validation, `n=7` held-out — 10–100× larger graphs, unseen shapes/SCCs); (ii) different families (held-out FCYCLE/DELETE/zig-zag strata); (iii) different target (derivatives, not scalar `V`); (iv) different code (independent falsifier); (v) different regime (large-`n` adversaries, inflated motifs, DELETE-diverged histories); (vi) different domain (out-of-domain panel); (vii) mutation controls. `CROSS_N_STABLE` only after ≥1 untouched size. Any post-holdout tweak → new ID + new holdout plan. All witnesses/counterexamples/failed hypotheses preserved forever.
5. **Why this is stronger than train/test split:** held-out items differ in *combinatorial kind* (new Catalan shapes, new SCC topologies, new cost regimes, new scale), not just random sample — plus exactness (no tolerance to hide behind) and implementation independence (no shared-bug survival).
